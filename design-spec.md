# Design Specification

Below is the 8‑step spec for aligning the site to your provided mockup detail-for-detail.

## 1. Overall Color & Background
- Match the primary, secondary, and background colors exactly as in the design.
- Apply page‑level background gradients and section‑specific backgrounds per mockup.

## 2. Typography & Layout
- Configure Tailwind theme overrides for precise font sizes, weights, line‑heights, and letter‑spacing.
- Ensure headings, body text, and buttons use the exact typography specs.

## 3. Navigation Bar
- Set logo size and padding to match mockup.
- Implement hover, active, and scroll‑state animations (underline or highlight).

## 4. Hero Section
- Mirror the exact left/right column widths, whitespace, and element spacing.
- Style buttons (corners, shadows, gradients, padding) to mockup specs.
- Add the hero background image or SVG as shown in the design.

## 5. Section Spacing & Dividers
- Enforce exact vertical padding and max‑width for each section.
- Insert SVG wave or border‑top dividers between sections to match design.

## 6. Card Styles
- Refine Benefits, Pricing, and Testimonials cards with exact corner radii, shadow depth, border thickness, and padding.

## 7. Animations & Interactions
- Add all hover, focus, fade‑in, and scroll‑triggered animations per the mockup.
- Ensure button and link click/tap feedback matches.

## 8. Footer & Details
- Align footer background, typography, and small decorative elements exactly as drafted.
